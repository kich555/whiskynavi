# 보틀 아카이브 — `/archive`, `/archive/[bottleId]`, `@modal/(.)archive/[bottleId]`

사용자 화면. 위스키내비에서 발매한 모든 보틀을 둘러보는 카탈로그. 다면 필터·정렬로 탐색하고, 카드 클릭 시 모달로 상세를 띄운 뒤 원하면 전체 페이지로 전환할 수 있는 two-step 상세 구조.

## 라우트 맵

| 경로 | 유형 | 비고 |
|---|---|---|
| `/archive` | 보틀 카탈로그 목록 | ★ 이 화면군 핵심 |
| `/archive/[bottleId]` | 보틀 상세 전체 페이지 | 모달에서 "자세히 보기" 또는 직접 진입 |
| `@modal/(.)archive/[bottleId]` | 인터셉팅 모달 상세 | 목록에서 카드 클릭 시 발동 |

## 공용 컴포넌트

목록·상세 양쪽에서 재사용되는 UI. 동작 방식 명시.

| 컴포넌트 | 역할 | 동작 |
|---|---|---|
| `BottleCard` | 보틀 카드 (이미지, 브랜드, 이름, 증류소, 도수) | `<Link href="/archive/[id]">` — 클릭하면 인터셉팅 모달 발동. 이미지 클릭 시 라이트박스 확대 |
| `RepresentativeImageCarousel` | 대표 이미지 캐러셀 | 모달·전체 페이지 공용. 이미지 없으면 이름 텍스트 노출 |
| `RichTextContent` | 테이스팅 노트 리치 텍스트 렌더 | `sanitizeRichTextContent`로 XSS 필터링 후 렌더 |
| `Pagination` (archive 전용) | URL 기반 페이지네이션 | `<Link href>` 기반 — 북마크/공유 가능. `totalPages <= 1`이면 미렌더. 첫 페이지에서 "이전"·끝 페이지에서 "다음" 비활성화(opacity 30%) |
| `ArchiveSortSelect` | 정렬 기준 + 방향 선택 | 필터 상태(URL) 동기화 — `router.push` 기반 |

**"목록으로 돌아가기" 버튼 패턴**: 상세 전체 페이지(`/archive/[bottleId]`) 상단. `<Link href="/archive">` 사용 — `router.back()`이 아닌 href 링크. 직접 진입(공유/북마크)해도 항상 목록으로 안전하게 이동.

## 페이지별 맥락

### /archive — 보틀 카탈로그 목록 ★

위스키내비 발매 전체 보틀을 그리드로 탐색. 이 화면군의 핵심.

**상단 Hero**: 대형 타이틀 "아카이브" + 부제 "위스키내비에서 발매한 모든 제품을 둘러보세요." 배경에 `ARCHIVE` 거대 텍스트 + 장식 그리드 라인.

**레이아웃**: 데스크톱은 좌측 사이드바 필터 + 우측 카드 그리드. 모바일은 상단 검색바 + 시리즈 칩 + 그리드.

**보틀 카드 그리드** (카드 클릭 = 인터셉팅 모달):

| 이미지 | 브랜드 | 보틀명 | 증류소 | 도수 |
|---|---|---|---|---|
| (썸네일) | 글렌피딕 | 글렌피딕 18년 셰리 오크 | 글렌피딕 | 43% |
| (썸네일) | 맥콜 | 맥콜 12년 더블 캐스크 | 맥콜 | 40% |

- **카드 클릭**: `<Link href="/archive/[id]">` → 인터셉팅 모달 발동
- **이미지 클릭**: 라이트박스로 이미지 확대 (카드 링크와 분리)
- **이미지 없음**: 보틀명 텍스트가 링크 역할
- **반응형 그리드**: 모바일 2열, 데스크톱 3열

**사이드바 필터** (데스크톱 전용, `lg:block`):

| 필터 | 유형 | 동작 |
|---|---|---|
| 통합검색어 | 텍스트 입력 | 800ms 디바운스 (일반 필터는 300ms). 보틀명·시리즈명 검색 |
| 브랜드 | 체크박스 토글 | 다중 선택 |
| 시리즈 | 체크박스 토글 | 다중 선택 |
| 몰트 타입 | 체크박스 토글 | 다중 선택 |
| 증류소 | 드롭다운 다중 선택 | 콤보박스 형태 |
| 캐스크 타입 | 드롭다운 다중 선택 | 콤보박스 형태 |
| 도수(ABV) | 범위 슬라이더 | 40~80 기본값 |
| 빈티지 | 범위 슬라이더 | 1960~2025 기본값 |

- **활성 필터 영역**: 현재 적용된 필터 칩 표시. 개별 제거(x) 및 "전체 초기화" 버튼. 초기화 시 정렬(sort/direction)은 유지
- **모바일 검색바**: 사이드바 대신 상단 검색 입력 + 시리즈 가로 스크롤 칩. 필터 UI는 시리즈와 키워드만 제공 (상세 필터는 데스크톱 전용)

**정렬**:

| 정렬 기준 | 정렬 방향 |
|---|---|
| 등록순 / 병입순(기본) / 증류일순 / 숙성년수순 | 내림차순(기본) / 오름차순 |

**페이지네이션**: 페이지당 12병. 5페이지 초과 시 `...` 생략. URL `page` 파라미터 기반.

### /archive/[bottleId] — 보틀 상세 전체 페이지

모달에서 "자세히 보기" 또는 직접 URL 진입 시 표시되는 전체 상세.

**상단**: "목록으로 돌아가기" → `<Link href="/archive">` ⚠️ 공용 패턴

**3열 그리드** (데스크톱, 모바일은 1열 스택):
1. **이미지 캐러셀** — 대표 이미지 + 추가 이미지 슬라이드
2. **기본 정보** — 브랜드, 증류소, 몰트 타입, 도수, 캐스크, 캐스크 No., 증류일, 병입일, 용량. 값 없으면 "-"
3. **테이스팅 노트** — 리치 텍스트 렌더. 내용 없으면 "테이스팅 노트가 제공되지 않았습니다." 표시. 데스크톱은 max-height 500px 스크롤

### @modal/(.)archive/[bottleId] — 인터셉팅 모달 상세 ⚠️ 특수

**목적**: 목록에서 카드 클릭 시 전체 페이지 이동 없이 모달로 빠르게 상세를 들여다보는 two-step 구조. Next.js 인터셉팅 라우트(`(.)`)로 구현 — 같은 세그먼트 레벨에서 `/archive/[bottleId]`를 가로챔.

**특수 동작**:
- **모달 닫기 = `router.back()`**: `onOpenChange(open → false)` 시 `router.back()` 호출. 브라우저 히스토리를 한 단계 되돌려 목록으로 복귀. 새로고침/직접 진입 시엔 히스토리에 이전 페이지가 없을 수 있음 — 그 경우 `@modal/default.tsx`(null 렌더)가 fallback
- **`defaultOpen`**: 모달 진입 시 즉시 오픈. 별도 트리거 없음
- **로딩 skeleton**: `loading.tsx`가 모달 프레임 + skeleton을 렌더 — 보틀 데이터 페칭 중에도 모달 형태 유지
- **직접 URL 접근**: `/archive/[bottleId]` 직접 입력 시 인터셉팅이 발동하지 않고 전체 페이지(`/archive/[bottleId]/page.tsx`) 렌더. 모달은 클라이언트 사이드 내비게이션에서만 동작
- **모바일: 모달 대신 전체 페이지로 하드 네비게이션** ⚠️: 모바일 뷰포트에서는 모달을 렌더하지 않고 `window.location.href`로 `/archive/[bottleId]`에 하드 네비게이션. `router.replace` 등 클라이언트 네비게이션을 쓰면 인터셉팅 라우트가 다시 매칭돼 모달로 재진입해버리므로, 하드 네비게이션으로 인터셉션 자체를 우회
- **모달 레이아웃**: 2열 그리드(이미지 + 정보). 테이스팅 노트는 하단 전체 폭. 전체 페이지(3열)보다 압축된 뷰

**상세 정보 필드** (모달·전체 페이지 공통):

| 필드 | 예시 |
|---|---|
| 브랜드 | 글렌피딕 |
| 증류소 | 글렌피딕 |
| 몰트 타입 | 싱글 몰트 |
| 도수 | 43% |
| 캐스크 | 셰리 오크 |
| 캐스크 No. | 4872 |
| 증류일 | 2004-04-15 |
| 병입일 | 2022-03-10 |
| 용량 | 700ml |

## 데이터 흐름 (개요)

- **목록**: RSC. 검색 파라미터(`getApiV2BottlesParameters`)로 필터 옵션(브랜드/시리즈/증류소 등 전체 목록) 페칭 → `ArchiveClientShell`에 전달. 보틀 목록은 `<Suspense>` 내 `BottleList`(RSC)가 `getApiV2Bottles`로 페칭. `Suspense key`를 searchParams JSON으로 설정해 파라미터 변경 시 스트림 리페치
- **상세(전체/모달)**: RSC. `getApiBottlesId(id)`로 단건 페칭. 인증 불필요(공개 카탈로그)
- **필터 동기화**: `useFilters` 훅이 클라이언트 필터 상태를 URL searchParams로 변환. 디바운스(300ms/키워드 800ms) 후 `router.push('/archive?...', { scroll: false })`. 필터 변경 시 항상 page 1로 리셋
- **URL 인코딩**: 배열 필터는 CSV(쉼표 구분)로 직렬화. 기본값과 동일한 필터는 URL에서 생략(예: ABV 40~80, 빈티지 1960~2025)
- **정렬 기본값**: 병입순(병입일) 내림차순. 기본값일 때만 URL에서 생략

## 외부 의존

- **API**: 원격 백엔드 `api.whiskynavi.com` (Orval 코드젠 클라이언트). 인증 불필요 — 공개 카탈로그
- **이미지**: `ImageWithFallback` 폴백 + `ImageLightbox` 확대 모달
- **리치 텍스트**: `sanitizeRichTextContent` XSS 필터링 → `RichTextContent` 렌더
