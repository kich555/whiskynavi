# 관리자 공용 셸 & 대시보드 — `/admin`

## 라우트 맵

| 라우트 | 설명 |
| --- | --- |
| `/admin/*` (레이아웃) | 전체 관리자 라우트에 적용되는 인증 가드 + 사이드바 셸 |
| `/admin` | 대시보드 홈 (통계 카드 + 빠른 링크) |
| `/admin/*` (에러 바운더리) | 전체 관리자 라우트에 적용되는 공용 에러 화면 |

## 공용 컴포넌트

| 컴포넌트 | 역할 | 동작 |
| --- | --- | --- |
| AdminLayoutClient | 사이드바 열림/닫힘 상태 제공 (`useSidebar`) | 사이드바 통계 슬롯과 `children`을 감싸는 클라이언트 셸 |
| AdminHeader | 페이지 상단 헤더 | title, 사이드바 토글, (옵션) 검색 |
| SidebarStatsSection | 사이드바 하단 통계 패널 | 서버에서 6개 지표를 fetch해 스트리밍 렌더 |

## 페이지별 맥락

### ★ 인증 가드 (레이아웃)

`/admin`으로 시작하는 모든 라우트에 진입하기 전, 서버에서 세션을 검사한다.

- 세션에 `accessToken`이 없으면 `/sign-in`으로 리다이렉트
- 로그인되어 있어도 `ROLE_ADMIN` 권한이 없으면 `/`(홈)으로 리다이렉트
- 검사를 통과하면 사이드바 셸과 함께 하위 페이지를 렌더

### ★ 대시보드 홈 (`/admin`)

두 영역으로 구성되며, 각각 독립적인 스트리밍 경계를 가진다.

- **통계 카드**: 전체 회원 / 총 주문 / 등록 제품 / 예약 공고 / 예약 신청 / 사업자 회원 수. 서버에서 각 목록을 1건만 조회해 총 개수만 취득하며, 개별 요청이 실패해도 해당 카드만 "-"로 표시되고 나머지는 정상 노출됨 (전체 실패로 전이되지 않음). Suspense로 감싸져 있어 카드 영역이 로딩 스켈레톤 → 실제 값으로 전환됨
- **빠른 링크**: 회원/보틀/보틀예약/보틀주문/구매내역 대량 등록/일반상품/일반상품 등록/일반상품판매공고/일반상품주문/일반상품판매공고 등록/멤버십/블랙리스트/게시판 관리로 이동하는 총 13개 카드 그리드. 카드 클릭 시 해당 관리 페이지로 이동만 하며, 별도 동작(모달/폼)은 없음
- 이 페이지에는 검색 입력이 없고, 헤더에는 사이드바 토글만 제공됨

### ⚠️ 사이드바 통계 (레이아웃 공용)

대시보드 카드 통계와 **별도 화면 영역**으로, 사이드바 하단에도 동일 구성의 통계 패널이 렌더된다.

- 항목 구성은 대시보드 통계 카드와 동일한 6개 지표(전체 회원/총 주문/등록 제품/예약 공고/예약 신청/사업자 회원)
- 두 영역 모두 같은 통계 조회 함수를 호출하며, 이 함수는 `React.cache`로 감싸여 있어 **한 요청 안에서는 실제 호출이 한 번만 일어나고 결과가 재사용됨** — 레이아웃(사이드바)과 페이지(대시보드 카드)가 같은 요청 트리에서 렌더되므로 두 영역의 숫자는 항상 일치함
- 개별 지표 조회는 `Promise.allSettled`로 병렬 처리 — 하나가 실패해도 나머지 지표는 정상 값을 유지하고 실패한 지표만 "-"로 표시

### ⚠️ 공용 에러 화면 (에러 바운더리)

`/admin` 하위에서 렌더 중 예외가 발생하면 공용 에러 화면으로 대체된다.

- 에러 메시지가 정확히 "인증이 만료되었습니다. 다시 로그인해주세요."이거나 `digest`에 `AUTH_ERROR`가 포함된 경우 → 인증/권한 문제로 간주해 별도의 제목·설명 노출
- 그 외 에러는 일반 오류 문구로 노출
- 두 경우 모두 "다시 시도"(현재 화면 재시도)와 "홈으로 이동"(`/`) 두 가지 액션을 제공
- 개발 모드에서만 콘솔에 에러를 로깅하고, 펼침 가능한 상세 스택트레이스 패널을 노출함 (운영 환경에는 노출 안 됨)

## 데이터 흐름 (개요)

대시보드 통계와 사이드바 통계는 서로 다른 서버 컴포넌트(각각 페이지/레이아웃)에서 렌더되지만, 공통 통계 조회 함수를 통해 백엔드 목록 API들을 페이지 크기 1로 호출해 총 개수만 취합한다. 이 함수가 `React.cache`로 메모이즈되어 있어 한 요청 내 중복 호출이 실제 네트워크 요청으로 이어지지 않고 재사용되며, 두 영역이 항상 같은 숫자를 보여준다. 개별 API 호출이 실패해도 해당 지표만 비어있는 값("-")으로 표시되고 나머지 지표 렌더링에는 영향을 주지 않는다.

## 외부 의존

- next-auth 서버 세션 (`getServerSession`)으로 인증/권한 검사
- 회원/주문/보틀/예약공고/예약신청/사업자회원 목록 API(개수 조회용)
